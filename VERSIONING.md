# Versioning Policy

Applies to `openapi.yaml` and the event contract for Pair 07.

## Current Version

- v1.0.0 (19 tháng 5, 2026)

## Semantic Versioning

- MAJOR: Breaking changes (rename/remove fields, change required fields, change `eventType`, change topic name).
- MINOR: Backward-compatible additions (new optional fields, new event types).
- PATCH: Documentation/example fixes, typo fixes.

## Deprecation Rules

- Deprecate before removal when possible.
- Announce MAJOR changes with migration notes.
